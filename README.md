# MalangeniBlogProjectBackend
Java backend for the Malangeni blog (APIs and admin).

About

This repository provides the backend APIs for the Malangeni blog, including content management endpoints, admin utilities, and database migrations.

Features

- REST API for posts and authors
- Admin endpoints and migrations

Tech Stack

- Java
- Spring Boot (or similar)

Quick start

```bash
# clone
git clone https://github.com/gceenare/MalangeniBlogProjectBackend.git
cd MalangeniBlogProjectBackend
# build and run
```
